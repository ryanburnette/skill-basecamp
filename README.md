# skill-basecamp

**Archived.** After Basecamp CLI v0.9.0, use the official skill instead:

- Repo: [basecamp/skills](https://github.com/basecamp/skills) (`skills/basecamp`)
- Install: `npx skills add basecamp/skills`
- Also embedded in the CLI: `basecamp skill show` / `basecamp skill install`

This fork existed to track CLI bugs and keep local workflow preferences. v0.9.0 fixed the bugs that justified maintaining a separate copy (search, due-date updates, listless todos, todo steps on `todos show`, completion subscribers). Prefer the official skill going forward; put personal conventions in project `AGENTS.md`, not a forked skill.
